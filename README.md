Docker & Portainer — Debian 13 ARM64
Ce projet documente l'installation et l'administration de Docker Engine et Portainer sur un système Debian 13 (Trixie) ARM64.

L'objectif est de disposer d'une base Docker complète et administrable depuis Linux, avec Portainer comme interface Web pour gérer les conteneurs, images, volumes, réseaux et stacks Docker.

📖 Installation étape par étape
Les instructions complètes d'installation sont disponibles dans le fichier : instructions.md
